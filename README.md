# Siva Club – Node.js application with Docker Swarm & Jenkins CI/CD

Siva Club is a production-style **Node.js 20 web application** designed with a premium Indian sports and wellness club theme. The project demonstrates a complete **DevOps CI/CD workflow** using **Docker, Docker Swarm, Jenkins, GitHub Webhooks, and SSH agents**.

## Project overview

This project showcases a real-world deployment pipeline where every code change pushed to GitHub automatically triggers Jenkins, builds a Docker image, pushes it to Docker Hub, and deploys the application to a Docker Swarm cluster.

**Application features**

* Modern responsive UI
* Gym, swimming pool, running coach, basketball, volleyball, yoga sections
* Health check endpoint
* Production-ready Node.js server
* Dockerized deployment
* Docker Swarm orchestration
* Jenkins automated CI/CD

## Running locally

### Clone the repository

```bash
git clone https://github.com/Siva-Satyanarayana/siva-club_Node.js-application.git
cd siva-club_Node.js-application
```

### Install dependencies

```bash
npm install
```

### Start the application

```bash
npm start
```

The application runs on:

```text
http://localhost:3000
```

## Docker deployment

### Build the image

```bash
docker build -t polavarapusiva/siva_club:app .
```

### Run the container

```bash
docker run -d -p 3000:3000 polavarapusiva/siva_club:app
```

### Verify

```bash
docker ps
```

## Docker Swarm deployment

### Initialize Swarm

On the manager node:

```bash
docker swarm init
```

### Join the worker node

Use the join token generated by the manager:

```bash
docker swarm join --token <TOKEN> <MANAGER-IP>:2377
```

### Deploy the stack

```bash
docker stack deploy -c docker-compose.yml siva-club
```

### Verify services

```bash
docker service ls
```

### Verify replicas

```bash
docker service ps siva-club_club
```

## Docker Compose configuration

The stack deploys **3 replicas** of the application service.

Example:

```yaml
services:
  club:
    image: polavarapusiva/siva_club:app
    ports:
      - "3000:3000"
    deploy:
      replicas: 3
```

## Jenkins CI/CD pipeline

The project uses a declarative Jenkins pipeline.

### Pipeline stages

1. Clean workspace
2. Checkout source code
3. Build Docker image
4. Push image to Docker Hub
5. Deploy to Docker Swarm
6. Verify deployment
